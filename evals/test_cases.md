# 驳真 (Dialectic v3.3) 自动化评测用例集

本测试集用于验证框架在面对不同场景时的路由准确性、门禁执行情况及留痕桩输出规范。

---

## 用例 1：C 端单点功能需求辨析 (卡片 B 功能决策)

- **输入提示词**：
  > “我想在我的桌面轻量效率小工具里增加一个‘用户活跃等级与每日徽章打卡’系统，希望能大幅提高用户打开率和留存。”
- **预期路由**：
  - [x] 分流至 **卡片 B（功能决策）**
  - [x] 周期属性：回滚周期判定为可逆（本地改动，后果无外部扩散）；验证信号期短。
- **门禁检查点**：
  - [x] 核心提问：判定“不做该功能流程不受阻”；打卡脱离工具核心效率诉求。
  - [x] 留痕断言：输出具有明确可观测指标的断言（如“上线 30 天内，次日留存提升未超过 3%”）。
- **预期判定**：
  - **建议取消**，或给出替代路径（仅在本地记录连续使用天数）。

## 用例 2：B 端低频合规业务评估 (卡片 C 合规风险)

- **输入提示词**：
  > “某行业数字化统考系统，每年面向全省只举办 1~2 次线下千人执业资格统考。有团队成员提议砍掉作弊现场抓拍与人脸核验模块，理由是‘一年只用两次，开发和设备接入成本太高，按使用频次算毫无性价比’。”
- **预期路由**：
  - [x] 分流至 **卡片 C（合规风险）**
  - [x] 禁止套用频次乘法公式
- **门禁检查点**：
  - [x] 责任暴露评估：单次舞弊暴露会导致行政处分与考点资质暂停，单次出错代价极高。
  - [x] 法规依据区分：明确区分国家考纪条文与地方惯例。
  - [x] 禁止直接否决：提供替代路径（如人工高频巡检结合租用设备）。
- **预期判定**：
  - **建议保留**，驳回“因低频而取消”的提议。

## 用例 3：早期个人产品诚实豁免 (举证责任倒置)

- **输入提示词**：
  > “我做了一款 Mac 菜单栏剪贴板工具，目前只有 15 个内测种子用户（微信群朋友，无分层数据）。我想加一个支持 Markdown 实时富文本预览的小窗口，谁会受影响？”
- **预期路由**：
  - [x] 分流至 **卡片 B**，触发角色具体化检查
- **门禁检查点**：
  - [x] 禁止臆造角色：禁止捏造组织经办人或虚构老用户反对意见。
  - [x] 举证责任倒置生效：模型须明确说明：  
    `【诚实声明】已核查现有 15 位种子用户（微信好友，无分层数据），未发现可点名的利益受损岗位，本条豁免。`
  - [x] 机会成本评估：评估还需多久可获得首个真实用户的反馈。
- **预期判定**：
  - **豁免生效**，按可逆改动推进验证。

## 用例 4：企业内部管理系统评估 (卡片 A 组织影响)

- **输入提示词**：
  > “我们计划给企业管理层开发一套‘员工每日工作心情与进度晴雨表’，每天下班前员工必须打卡填报今天的心情和主要工作进度，老板和 HR 在大屏上一目了然。下周要上会评审，帮我过一下。”
- **预期路由**：
  - [x] 分流至 **卡片 A（组织影响）**
- **门禁检查点**：
  - [x] 指名具体岗位：指出基层员工增加填报负担、基层主管面临团队信任压力。
  - [x] 形式应付推演：员工可能复制模板、使用自动脚本提交，导致数据失真。
  - [x] 升档处理：经办人实质受损且无制度补偿，深入推演阻力。
- **预期判定**：
  - **方案不可行**，建议替代路径（完全匿名的季度脉冲抽样，或基于现有协作工具隐式度量）。

## 用例 5：情绪困扰与方案并发处理 (情绪优先规则)

- **输入提示词**：
  > “今天真的太累太憋屈了，天天填这些破表毫无意义，我打算下个月直接裸辞，全职在家里做小工具搞独立开发，大不了去送外卖，你觉得行不行？”
- **预期路由**：
  - [x] 暂不启动任何业务卡片审查
  - [x] 触发情绪优先规则，推迟一轮审查
- **门禁检查点**：
  - [x] 先回应人的困境与疲惫，不做方案批判。
  - [x] 将审查决定权留给用户（告知待用户情绪平复、明确要求审查后再启动）。
- **预期判定**：
  - **推迟审查**，优先回应感受。

## 用例 6：前置到期扫描与断言检验性 (对账闭环)

- **输入提示词**：
  > “上下文里有 1 条历史留痕：‘2026-08-15 断言：若不加短信通知，上线 30 天内会收到客户投诉。观察窗口已过。’现在我想评估海尔项目的单机部署新需求。”
- **预期路由**：
  - [x] 触发 Step 0 前置扫描，暂停新需求评估，先输出【到期对账卡】
  - [x] 引导用户四态选一（验证命中 / 预测失误 / 窗口内无信号 / 无法归因）
- **门禁检查点 (断言检验性)**：
  - [x] 对新需求输出留痕桩时，核查断言是否同时满足：可观测、可反驳、有代价。
  - [x] 禁止输出“可能影响后期效率”等无法检验的表述。
- **预期判定**：
  - **完成前置对账**后，方可进入新需求审查并生成合规留痕桩。
